# Свидание — приглашение

Своя версия invitik.ru, но без оплаты и регистрации: одна страница, одна девушка, один вопрос.

**Публично:** https://fds-khv-stack.github.io/svidanie/ · репозиторий `fds-khv-stack/svidanie`
(прежний адрес `/invite/` больше не работает — репозиторий переименован 19.10.2026)

## Что править
Только `js/config.js`: её имя, вопрос, даты, время, занятия, секретное сообщение, подпись.
Фото/гифка — положи в `img/` и укажи путь в `photo`.
Котики на экране входа — `img/cat-play.webp` и `img/cat-love.webp` (на финале — `img/cat-lie.webp`),
включаются флагом `cats: true|false` в конфиге (и в конструкторе есть галочка).
Исходная картинка режется скриптом `scripts/crop_cats.py` (Pillow, через `uv run --with pillow`).

## Куда приходит ответ (только GitHub, без серверов)

`js/config.js` → `formsubmitEmail`: ответ уходит письмом через formsubmit.co прямо со страницы на Pages.
**Один раз нужно нажать «Activate Form» в письме от FormSubmit** — до этого ответы не доставляются.
Минус: адрес почты виден в исходнике публичной страницы.

Пробовал Web3Forms как альтернативу без раскрытия почты — он за Cloudflare, браузерный `fetch` не проходит
(`TypeError: Failed to fetch`, с сервера 403 «Just a moment…»), поэтому код убран, чтобы не было мёртвого пути.
Если хочется канал с мгновенным уведомлением и без VPS — следующий вариант Google Forms
(ответ POST-ится в `formResponse` формы, попадает в таблицу + письмо); нужна одна форма, заведённая руками.

## Конструктор приглашений

`https://fds-khv-stack.github.io/svidanie/constructor.html` — страница-редактор (в индекс не пускаем,
`noindex`). Собираешь приглашение в форме, справа живое превью и готовая ссылка.

- **Что можно настроить:** её имя, свою подпись, текст вопроса (`{name}` подставляется), дни, время,
  занятия (смайлик в начале строки), текст секретного конверта, поведение кнопки «Нет», почту для ответов,
  **вайб** (6 тем: Коралл, Розовый закат, Лаванда, Мята, Ночь, Золото) и шрифт заголовков (геометрия / рукописный / serif).
- **Данные живут в самой ссылке:** `#d=<base64url(JSON)>` — сервер не нужен, работает на Pages.
  Ссылка ~950 символов; черновик сохраняется в localStorage.
- **Отправка ответов:** в ссылке переносится почта из поля «Ответы»; в превью отправка отключена
  (`&preview`), поэтому тестовые клики не шлют письма.
- **Параметры ссылки:** `#d=…` — данные, `&preview` — не отправлять ответы, `&skip` — сразу к вопросу.

Файлы: `constructor.html`, `js/constructor.js` (форма → ссылка), `js/params.js` (разбор ссылки + темы,
подключается между `config.js` и `app.js`), `css/constructor.css`, `css/vibe.css` (шрифтовые режимы и тёмные вайбы).

**Подводный камень:** смена только hash в `iframe` не перезагружает документ — превью открывается
как `index.html?t=<метка времени>#d=…`, иначе тема и текст не обновляются.

## Безопасность — что где видно

Проверено 19.10.2026 (репозиторий `fds-khv-stack/svidanie`, Pages — публичный):

| Что | Состояние |
|---|---|
| 🔑 Токены, ключи, пароли в репозитории и в истории git | **нет** (поиск по `ghp_`, `github_pat_`, `<id>:<hash>`, `AKIA`, приватным ключам — пусто) |
| 🛡 Внедрение кода через «свой вариант» | **безопасно**: весь пользовательский текст рисуется через `textContent`; тест с `<img onerror>` и `<script>` остался текстом, скрипты не выполнились |
| 📄 Имя, вопрос, текст секрета, PIN, почта | **видны** в `js/config.js` любому, кто откроет репозиторий |
| 🔒 PIN `2310` | это **не защита**, а милый ритуал: код лежит в открытом файле, проверка в браузере, снимается правкой JS или `sessionStorage` |
| 🔗 Ссылка = конфиг | данные едут в `#d=…`: тот, кто собрал свою ссылку, может подставить **свой** адрес ответов. Ссылку никому не пересылать |
| 📧 Почта в исходнике | `formsubmitEmail` виден — писать на алиас вида `name+svidanie@gmail.com`, чтобы отсекать спам |
| 🤖 Telegram | намеренно выключен: токен бота в публичном файле = доступ к отправке и чтению входящих бота |
| 📦 Внешние зависимости | Google Fonts (шрифты) и formsubmit.co (ответы). Картинки и видео — свои, с GitHub |

**Если нужно убрать личное из публичного:** приватный репозиторий + свой хостинг (Pages из приватного — только на платном плане),
либо держать персональные значения только в ссылке из конструктора, а в `config.js` оставить шаблон.

## Деплой на GitHub Pages
```bash
git add -A && git commit -m "правки" && git push
# Pages: ветка main, папка / (root) — обновляется через ~1 минуту
```

## Поведение кнопки «Нет»
`noMode: 'runaway'` — убегает (как на invitik). Ещё есть `shrink` (уменьшается),
`split` (размножается), `kiss` (исчезает с 😘).

## Локально
```bash
cd "G:/Мой диск/My_Project/invite"
python server.py
# открыть http://127.0.0.1:8770/
```
Без `server.py` страница тоже работает (просто открой `index.html`),
но ответ тогда никуда не придёт.

## Локальный сервер (необязательно)

`server.py` остался только для локальных опытов: отдаёт страницу и может писать ответы в
`answers.jsonl` (и в Telegram, если задать `TG_TOKEN`/`TG_CHAT`). **Для боевой версии на Pages он
не нужен** — решение от 19.10.2026: никакого VPS, всё живёт на GitHub.

## Проверено
Полный прогон в браузере (мобильный вьюпорт 390×844): вступление → «Да» → дата/время →
занятие → финал → конверт → ответ записан в `answers.jsonl`.
